# Governance

Model Distillation Recipes uses a maintainer-led governance model.

## Maintainers

Maintainers are responsible for:

- Defining project scope and technical direction.
- Reviewing and merging contributions.
- Maintaining tests, documentation, and supported configurations.
- Coordinating releases, security response, and NVIDIA open-source compliance.
- Enforcing the Code of Conduct.

Current project ownership is documented in `MAINTAINERS.md`.

## Contributions and Decisions

Community members may propose changes through issues and pull requests.
Maintainers seek technical consensus through public discussion when practical.
When consensus cannot be reached, maintainers make the final decision based on
project scope, correctness, maintainability, security, licensing, and
compatibility.

Substantial changes to training behavior, public interfaces, dependencies,
supported models or hardware, data formats, or reproducibility requirements
should be discussed in an issue before implementation.

## Releases

Maintainers determine release readiness and versioning. A release must satisfy
the documented test, security, licensing, reproducibility, and NVIDIA review
requirements.

## Conduct and Security

Community behavior is governed by `CODE_OF_CONDUCT.md`. Security reports must
follow `SECURITY.md` and must not be submitted through public issues.
